## 机器人来源

采用 Google DeepMind MuJoCo Menagerie 中的 Franka Emika Panda。
它包含七个机械臂转动关节、双指夹爪、碰撞几何、质量与惯量、关节限位及位置控制执行器。
七轴结构、关节冗余和双指操作适合学习桌面抓取，也符合实施文档 00、01 的选型。

官方模型与场景按固定提交保存在 `assets/robots/franka_emika_panda/`。
该目录的 `SOURCE.json` 记录来源、提交和各文件 SHA-256，`LICENSE` 保留 Apache-2.0 许可。

## 你来操作的第一步

1. 双击本目录的 `open.cmd`，打开官方 Panda 场景。
2. 点击 **Pause**。
3. 在左侧 **Simulation** 中找到 **Keyframe**，选择 `home`。
4. 点击 **Reset**，加载官方保存的起始姿态。
5. 观察基座、机械臂各段和夹爪，再展开右侧 **Controls**。

`home` 是模型作者保存的一组关节位置和控制目标。
选择这个关键帧后 Reset，会恢复该组位置、速度与控制量。
使用它可以把机器人的实际姿态和执行器目标一起恢复到明确起点。
这个场景复用了模型作者的地面与灯光。

## 这一轮需要理解的技术

| 术语 | 含义 | 在 Panda 上观察什么 |
|---|---|---|
| 关节 joint | 两段刚体之间允许怎样相对运动 | 七个机械臂关节各绕一根轴转动 |
| 自由度 DOF | 描述运动需要的独立变量 | 机械臂有七个关节角，夹爪有联动机构 |
| 执行器 actuator | 根据控制目标向关节或机构施力 | Controls 中前七项控制机械臂，最后一项控制夹爪 |
| 目标与实际状态 | 执行器接收目标，动力学产生实际运动 | 目标角改变后，关节需要一段时间才能接近它 |
| 正运动学 FK | 从关节角计算末端的位置和朝向 | 一个关节转动会改变夹爪的位置或朝向 |
| 逆运动学 IK | 根据末端目标求解一组关节位置 | 下一节点用于让夹爪接近方块 |

模型中 `joint1` 至 `joint7` 对应机械臂。
`finger_joint1`、`finger_joint2` 对应两根手指，模型已有联动约束。
八个执行器的名字是 `actuator1` 至 `actuator8`。

前七项位置控制输入以弧度表示，0.1 rad 约等于 5.7°。
第八项采用官方的 0—255 控制映射，0 对应闭合目标，255 对应张开目标。
受接触、力限和动态过程影响，实际开度和关节位置可能偏离目标。

## 下一次小实验

在 home 姿态下，只小幅改变 `actuator1` 的目标，例如从 0 调到约 0.1 rad。
然后点击 Run，观察机械臂怎样响应，再暂停。
每次只改一项，便于把控制输入与运动结果联系起来。

观察时记录三件事。

- 哪个关节开始转动，哪些连杆随之运动。
- 夹爪在空间中的位置或方向怎样变化。
- 暂停时修改目标与运行时执行运动之间的关系。

这次观察会连接到后续的 FK、IK 与抓取航点。每个术语都在对应的实际任务中继续拆解。

## 启动入口在做什么

`open.cmd` 指向本机已经安装 MuJoCo 的 Python，调用官方 `mujoco.studio.viewer`。
`--model` 指定官方 Panda 的 `scene.xml`，该场景再引用 `panda.xml` 和官方网格。
`--gfx=opengl_software` 沿用当前可用的窗口显示方式。
换电脑时需要调整启动脚本中的 Python 路径。
