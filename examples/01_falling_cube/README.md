# 第一个实验，方块落地

本实验帮助理解场景、状态和物理步进，也为后续抓取与放置核验打基础。

## 打开与观察

1. 双击本目录的 `open.cmd`。它调用本机已有的 MuJoCo 环境，并加载同目录的 `scene.xml`。
2. 窗口打开后会运行。点击 **Pause**，再点击 **Reset**，让方块回到初始位置。
3. 拖动左侧 **Speed** 滑块，观察百分比，调到约 10%。
4. 点击 **Run**，观察红色方块落到棋盘地面。
5. 再次点击 **Pause**、**Reset**，可以重新实验。

调到 10% 后，0.3 秒仿真过程大约需要 3 秒墙钟时间。物理步长与重力保持场景中定义的值。
当前 Studio 4.0.1 使用自己的速度控件，新窗口默认从 100% 开始。
如果打开时方块已经落地，使用 Pause → Reset → Run 重新观察。

## 先理解三个概念

| 概念 | 在这个实验中的含义 |
|---|---|
| 模型 | `scene.xml` 定义地面、方块、重力、质量、初始位置与外观 |
| 状态 | 当前方块的位置、朝向、速度等，运行时持续改变 |
| 步进 | MuJoCo 每次把物理时间向前推进 0.002 秒，并计算运动和接触 |

点击 Reset 会恢复模型的初始状态。点击 Run 会继续推进物理时间。
本例中方块的运动由重力和地面接触产生。

## 阅读 scene.xml

按文件顺序阅读即可。XML 中 `<标签 .../>` 定义一个元素，`属性="值"` 配置它。
`<!-- ... -->` 是供人阅读的注释。

| 元素或属性 | 为什么需要 |
|---|---|
| `option` | 定义物理步长与重力 |
| `statistic`、`visual` | 配置初始相机范围和角度 |
| `asset`、`light` | 提供地面材质与照明，方便观察空间关系 |
| `worldbody` | 容纳世界中的物体 |
| 地面的 `geom` | 提供可碰撞的地面 |
| 方块的 `body` | 定义刚体及其初始位置 |
| `freejoint` | 让方块可以自由移动和旋转 |
| 方块的 `geom` | 定义形状、碰撞几何、质量与颜色 |

`pos="0 0 0.60"` 的三个数依次表示 X、Y、Z，单位为米。
方块中心初始高度为 0.60 米，边长为 0.10 米，底面初始高度为 0.55 米。
落地静止后，方块中心大约在 0.05 米高处。接触求解会产生很小的数值偏差。

## 亲手改变一个条件

1. 先预测升高方块后，落地时间和落地前速度会怎样变化。
2. 用编辑器打开 `scene.xml`，找到 `<body name="cube" pos="0 0 0.60">`。
3. 把 `0.60` 改成 `0.90`，保存。
4. 启动参数启用了模型热重载。观察重新加载后的方块，并用 Pause → Reset → Run 重复观察。
5. 如果窗口没有更新，点击 **Reload**。语法错误时查看右下角的日志提示。
6. 比较后把高度改回 `0.60` 并保存。

每次只改变一个条件，便于把现象与改动联系起来。

## 这一步的完成标准

- 能打开场景，亲手运行、暂停和复位。
- 能指出初始高度、重力与步长分别在哪里定义。
- 能解释中心高度与底面高度的区别。
- 能通过一次高度修改，比较下落过程，并描述自己的观察。

当前使用 Python 3.12.10、MuJoCo 4.0.1。`open.cmd` 中的解释器路径对应本机已有环境，换电脑时需要调整。
本例采用 10 cm 方块以方便观察，01 正式机械臂场景中的方块尺寸会按抓取要求配置。
