## 1. 本阶段的研究问题

给定现有控制器和抓取技能，在有限测试预算下，怎样更有效地估计技能适用条件，并据此减少任务中的失败尝试？

研究对象固定为当前模型、控制器、传感配置和物体族。先选两个变量，例如物体距基座的平面距离和夹爪接近角度。范围由第 1 周试跑确定，使测试区间同时覆盖可成功、易失败和不确定区域。

平台根据已有结果选择下一个条件，形成主动探索。每次试验通过现有技能和物理核验执行，探索过程可以暂停、继续、预算终止和检查证据。

## 2. 需要掌握的知识

| 概念 | 直观含义 | 项目落点 |
|---|---|---|
| 条件成功率 | 同类条件与随机变化下成功的频次 | 每个条件区域的能力估计 |
| 混杂变量 | 同时改变的因素会干扰解释 | 固定控制器、物体族和基础场景 |
| 重复试验 | 观察微小初态、传感噪声等带来的变化 | 每格多次执行，保存不同随机种子 |
| 不确定性 | 样本有限时对成功率的认识范围 | 区间和未知标记 |
| 主动选点 | 将试验分配给信息不足或接近边界的条件 | 探索调度器 |
| 独立验证 | 使用预留条件检查能力预测 | 冻结后的验证集 |
| 生命周期 | 新证据可以修订能力结论 | 版本、限制、撤回和复核 |

每次重复明确随机来源，例如位置小扰动、初始朝向、传感噪声和夹爪闭合偏差。固定所有条件后的重复确定性运行用于复现，统计试验使用预先声明的扰动分布。

具体数值范围、物体质量、摩擦分布、桌面高度、试验时限和重置方式在实际配置中完整登记。试验核验与正常任务共享结果定义，探索只使用其需要的子任务判定。

每条试验保存条件、随机种子、初态、结果、失败类别、执行版本、耗时和原始事件路径。`trial_id` 全局唯一，重试保留原 ID 和尝试编号，已完成试验在恢复时按清单识别。

## 4. 选点、估计与边界

### 4.1 第一版可解释方法

用 5×5 网格覆盖二维空间。每个格保存试验数 `n`、成功数 `s`、成功比例和 Wilson 95% 区间。概率分数初始可用 Beta(1,1) 平滑后的 `(s+1)/(n+2)`，明确记录这是估计器输出。

主动选择按以下顺序运行。

1. 用约 20% 预算覆盖分散的条件，建立初始分布。
2. 为剩余条件计算优先级，综合区间宽度、接近任务所需成功率阈值的程度和邻格结论差异。
3. 每轮保留少量均匀探索机会，避免局部区域长期未测。
4. 按固定规则选择下一格，在格内采样实际条件并运行。
5. 更新计数、区间与静态能力图，记录本次选点依据。

优先级公式、权重和随机比例在开发实验中确定，并在对照前冻结。随机基线均匀选择条件，固定扫描基线按预定覆盖顺序运行，三者共享预算单位和基础技能。

80 次预算初始可分配为 16 次覆盖、44 次方法选点和 20 次可靠区域确认。确认阶段按预先固定的规则选择待确认格，所有方法使用同一规则，并分别报告前 60 次与全部 80 次的预测效果。该安排使探索覆盖和在线可用证据各有预算，实际是否达到验证阈值由结果决定。

### 4.2 验证状态的初始规则

| 状态 | 条件与含义 |
|---|---|
| 候选 | 已定义技能、变量和结果标准 |
| 待验证 | 有声明或初步样本，证据尚少 |
| 验证中 | 探索任务正在增加样本 |
| 已验证 | 指定条件格样本数至少 20，Wilson 下界达到预设可靠性阈值，例如 0.8 |
| 受限 | 已测条件的可靠性不足，或适用范围收缩 |
| 需复核 | 控制版本、模型参数发生相关变化，或新失败证据与旧判断冲突 |
| 失效 | 控制入口不可用、明确版本不兼容或复核撤回 |

有限预算下，部分格会保留未知或待验证。图中显示样本数、区间与覆盖范围。格外条件标为未覆盖，连续边界仅作为基于已测格的估计展示。

单次执行失败首先增加证据并触发必要复核。永久失效需要明确的版本或能力依据。

## 5. 能力记录与在线接入

能力记录保存机器人、技能、观测特征、已测范围、估计方法、控制与传感版本、证据 ID、样本统计、验证规则、状态和能力版本。实验条件中的真实参数仅进入核验与实验记录，在线前置条件使用可获得的观测特征。

更新流程为完整试验落盘 → 核验结果 → 计算候选记录 → 校验来源与版本 → 原子发布新能力版本。发布使用预期旧版本进行条件更新，冲突时重新合并证据。中断后从已完成试验清单恢复，未完成试验标记为中断。

Harness 查询当前目标条件对应的能力记录，展示适用、受限或未知依据。能力版本变化使旧决策请求重新校验。执行中的技能按监督器评估处理，新版本对后续选择生效，危险证据触发即时暂停和复核。

在线任务提供三种可比较配置。

- 人工能力声明。
- 已探索的能力表。
- 同一记录中去掉边界估计的配置，用于观察证据使用的贡献。

三种配置保持技能和任务相同。研究成功率时同时报告拒绝、弃权、任务覆盖率和总完成数。

## 6. 预算与实验安排

先运行 12 次试验检查复位、核验、选点和记录。主比较的初始计划为每种选点方法 80 次、3 个独立探索种子。主动与随机合计 480 次执行，固定扫描可在同预算试跑中补充。

预留一组独立条件，例如 24 个连续空间点、每点 10 次重复，共 240 次物理验证。它们用于评价各能力表的预测、边界错误和区间覆盖。条件清单在方法调参前固定，并记录哈希。实际试验量依据头部试跑耗时登记，文档 06 汇总总预算与样本量。

相同物理验证结果可评价多个冻结后的能力表，前提是机器人、控制器和试验条件完全一致。验证标签的生成按独立种子执行。

指标包括预测误差、错误接受率、错误拒绝率、未知覆盖、校准情况和达到指定误差所用的试验数。未充分收敛时保留预算下结果，说明证据数量。

## 9. 常见问题与个人练习

| 现象 | 优先检查 |
|---|---|
| 所有条件都成功或都失败 | 测试范围、技能稳定性、核验阈值与变量是否实际生效 |
| 多次结果完全相同 | 随机源、初态小扰动和种子是否更新 |
| 能力图很平滑但证据稀少 | 插值方式、样本数量和未知区域显示 |
| 主动方法优势异常巨大 | 基线预算、验证标签、选点参数和测试集使用情况 |
| 使用能力表后完成数下降 | 拒绝、覆盖率、边界阈值和可替代技能 |

亲自计算一个条件的成功比例和 Wilson 区间，核对报告和原始样本。选出一次主动选点，解释当时已知什么、还缺什么。追溯一项“已验证能力”到原始试验，再检查它对一个在线决策的影响。
