## 1. 本阶段的验证问题

机械臂和移动机器人在身体、技能和任务结果上差异明显。此阶段检验观测、计划、候选、策略、监督、记录和评测的公共语义是否足够。

共通问题选择等待或继续、重新观察、局部恢复或升级。机器人专有的路径、接触、执行器和任务判定分别实现。

## 2. 移动场景与必要知识

### 2.1 主场景

一个带托盘的双轮差速底盘，在有两条可选通道的室内搬运区域，将初始已装载的方块送到目标停靠区。托盘为底盘结构的一部分，货物为独立动态物体，载货过程存在接触、滑动和掉落。

用户可以让临时障碍横穿通道、关闭一条通道、修改目的地，并观察等待、绕行、重新观察和升级。正常、可恢复和无法继续三条路径分别保存配置。

目标成功要求底盘与货物进入指定区域，货物仍在托盘有效范围，速度低于阈值并保持稳定窗口。任务起始条件明确标为已装载。

### 2.2 学习内容

| 概念 | 应用 |
|---|---|
| 差速运动学 | 将前进速度与转向速度变成左右轮速度 |
| 里程计 | 用轮速估计运动，并理解滑移造成的误差 |
| 占据栅格 | 将可观测障碍和已知地图表达成可通行区域 |
| 路径规划与跟踪 | 从栅格路径得到局部目标与速度指令 |
| 制动距离 | 用实测减速能力判断是否继续 |
| 本体约束 | 车宽、转向空间、货物稳定与速度限制 |

差速公式为 `v_right = (v + omega * track_width / 2) / wheel_radius`，`v_left = (v - omega * track_width / 2) / wheel_radius`。轮速单位为 rad/s，实际地面速度通过动力学与接触产生。

## 3. 模型、控制与感知方案

### 3.1 底盘模型

优先实现几何明确的小型 MJCF 底盘，包括刚体车身、两个驱动轮、被动支撑和固定托盘。驱动轮使用有限力矩的速度执行器，车身包含自由关节，轮轴方向、轮径、轮距、惯量与接触参数都由配置记录。

该模型承担有限任务的物理载体，测试直线、转弯、制动、碰撞和载货稳定。若被动支撑或轮胎接触校准持续阻碍任务，评估公开成熟底盘模型，记录来源、许可、兼容验证和改动。

### 3.2 专用技能

- `navigate_route` 跟踪选定通道的路径，持续检查局部障碍。
- `follow_alternate_route` 在允许通道中执行替代路径。
- `approach_dock` 低速进入目标区。
- `brake_hold` 减速并保持停止。
- `rescan` 更新传感观测。

规划先使用已知静态地图上的 A*，障碍按机器人外形与安全余量膨胀。动态障碍由模拟距离传感器加入局部地图。路径跟踪使用现成可解释的几何跟踪方法，如 pure pursuit，并配置速度与加速度限制。全局无路、局部临时阻塞和定位未知分别产生原因码。

### 3.3 观测与核验

场景配置区分事先已知的静态地图与在线动态对象。传感器使用射线距离、可见对象和允许的里程计，遮挡与观测年龄沿用统一契约。

初期允许标注清楚的模拟定位传感器提供带噪声位姿，同时保存其假设和误差。隐藏障碍、真实摩擦、精确货物状态属于核验信息。在线载货状态通过定义的托盘可见观测或模拟载荷传感信号获得。

## 4. 公共语义如何接入

| 语义 | Panda 的专用实现 | 移动底盘的专用实现 |
|---|---|---|
| 执行当前目标 | 抓取或搬运 | 沿路径载货移动 |
| 选择替代技能 | 改接近角度或航点 | 改通道或绕行 |
| 等待 | 稳定姿态保持 | 制动停止 |
| 重新观察 | 更新目标与夹爪观测 | 更新局部地图和目标 |
| 局部失败 | 空抓、滑落、路径受阻 | 跟踪受阻、轮滑、通道暂堵 |
| 任务升级 | 目标失效或局部方案耗尽 | 全局通道不可达或目的地改变 |

Harness 的候选统一使用 `kind`、`skill_id`、参数、前置条件、证据和解释。模型读取候选的含义及当前限制，专用执行器解析实际技能参数。

第二机器人接入时，先记录共享文件的修改清单。每项修改说明是契约缺陷修复、合理新增字段还是本体专用处理，公共接口调整后运行 Panda 全部回归。

## 5. 能力探索与跨机器人对照

### 5.1 移动能力探索

复用文档 04 的试验、证据、预算、状态和版本，选择一个变量，例如通道净宽或载货转向速度。成功条件包含通过通道、保持载货、约束满足和时间上限。

通道能力以当前车宽、控制器、传感和地面条件为前提，使用多次试验估计。将能力记录用于路径候选，展示一次更新前后的变化。预算先安排约 40 次试跑，样本不足的范围保留待验证。

### 5.2 共通判断测试

为两类机器人分别构造观测过期、临时障碍、局部失败可恢复、所有局部候选无效四类情境。保持同一决策策略与公共 schema，检查其选择观察、等待、替代或升级的行为。

记录本体任务成功率、共通决策分布和监督拒绝原因。共享机制的适配成本通过新增文件、修改文件、配置项、实际工时和是否需要训练分别描述。代码行数可作为辅助信息。

文档 06 加入每机器人独立配置的合理对照，衡量共享设置在效果与适配工作量上的取舍。

## 6. 场景切换、原生观察与后续集成

切换流程为停止旧运行 → 写入终态 → 递增 epoch → 释放旧模型 → 加载新模型和资产 → 发布新机器人档案与能力 → 等待首个状态 → CLI/原生确认可运行。

通用任务、运行、策略、事件检索、能力和报告使用一致的 CLI/数据契约。原生场景提供可读相机、模型、路线、目标与控制说明。07 根据档案接入第二场景、任务入口、干预按钮和报告页面。

## 7. 实施步骤

| 步骤 | 时间 | 可观察结果 |

## 9. 故障定位与个人练习

| 现象 | 优先检查 |
|---|---|
| 两轮同速却原地转向 | 关节轴、轮速正负号与初始姿态 |
| 底盘侧滑或跳动 | 轮胎接触、被动支撑、惯量、步长 |
| 路径可见却无法通过 | 外形膨胀、车宽、局部控制和通道能力 |
| 绕行后货物掉落 | 转向加速度、托盘摩擦和速度限制 |
| 新机器人需要大量公共分支 | 契约是否包含 Panda 专有假设 |

亲自用差速公式计算一次转向轮速，再比较实测。对照两种机器人的同类决策请求，解释公共字段和专有参数。选择一项公共接口修改，说明为什么需要它以及如何验证旧场景。

交接内容包含独立移动场景、动力学与导航记录、能力证据、共享决策测试、适配工作量和两场景回归。

- 轮式运动学可参考机器人教材中的差速模型。 [Modern Robotics 在线资料](https://modernrobotics.northwestern.edu/nu-gm-book-resource/)
- 地图、模型与执行器定义。 [MuJoCo 建模文档](https://mujoco.readthedocs.io/en/stable/modeling.html)
